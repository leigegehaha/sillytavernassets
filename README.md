# SillyTavernAssets

SillyTavern 角色卡 + 预设合集

## 目录结构

```
├── cards/          # 角色卡（32个分类，3506张）
│   ├── NTR/
│   ├── 同人/
│   ├── 世界卡/
│   └── ...
└── presets/        # 预设（463个文件）
    ├── 小克预设/
    ├── 调酒师1.5/
    ├── 预设1/
    └── ...
```

## 通过 jsDelivr 访问

```
https://cdn.jsdelivr.net/gh/leigegehaha/sillytavernassets@master/cards/分类名/文件名.png
```
